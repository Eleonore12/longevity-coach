# Activity catalog

Pick from here to keep sessions varied. For demo links and form cues, see `exercise-links.md`. Each entry shows the **minimum level** and the **equipment** it needs. Rotate modalities within a category, and avoid repeating the same specific activity within about 7 days unless it's an explicit progression.

## Endurance — Z1 / Z2
| Activity | Level | Equipment | Notes |
|---|---|---|---|
| Brisk walk / incline walk | all | none / treadmill | Easiest Z2 entry. Incline raises HR without impact. |
| Rucking (weighted backpack walk) | beginner+ | backpack | Builds Z2 plus loaded carry strength. |
| Easy run / run-walk | beginner+ | none | Use run-walk intervals if HR drifts above Z2. |
| Cycling (outdoor / indoor) | all | bike | Low impact and very controllable. |
| Rowing | beginner+ | rower | Full body. Technique first. |
| Swimming (steady) | beginner+ | pool | Joint-friendly. HR runs ~10 bpm lower in water. |
| Elliptical / ski-erg | all | gym | Low impact. |
| Hiking | all | outdoors | Great for long weekend Z2. |
| Dance / Zumba (steady) | all | none | Fun way to get Z2, which helps adherence. |

## VO2max — Z5 intervals
Use the progression ladder in `programming.md`. Modalities, from lowest to highest impact:
- Bike / spin
- Rower
- Ski-erg
- Swimming
- Incline treadmill / hill repeats
- Running intervals

## Strength
Build sessions from patterns, choosing variations that match the user's level and equipment:

| Pattern | Beginner | Intermediate | Advanced |
|---|---|---|---|
| Squat | Box squat, goblet squat | Goblet / front squat | Back / front squat |
| Hinge | Glute bridge, DB RDL | KB deadlift, RDL | Trap-bar / conventional deadlift |
| Push | Incline push-up, DB press | Push-up, DB bench, overhead press | Barbell bench, strict press, dips |
| Pull | Band row, TRX row | DB row, lat pulldown | Pull-ups, barbell row |
| Single-leg | Step-ups, split squat | Reverse lunge, Bulgarian split squat | Weighted Bulgarian, single-leg RDL |
| Carry | Farmer's carry | Suitcase carry | Heavy farmer's carry, overhead carry |
| Core | Dead bug, side plank | Pallof press, bird dog | Ab wheel, Copenhagen plank |
| Power (optional) | — | Med-ball throws, low box jumps | Jumps, KB swings, Olympic lift variants |

Formats to rotate through:
- Straight sets
- Supersets (push/pull)
- Circuits (time-limited)
- EMOM
- Tempo work (3-1-1)
